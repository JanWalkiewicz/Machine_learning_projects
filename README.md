# Machine_learning_projects

## PL

### 1. [Happiness_predict_project](./Happiness_predict_project) - projekt oparty na języku programowania Python
**Celem** projektu jest opracowanie modelu uczenia maszynowego służącego do predykcji poziomu szczęścia w poszczególnych krajach na podstawie wskaźników ekonomicznych, społecznych oraz regionalnych.
Projekt zawiera wszystkie etapy potrzebne do zbudowania efektywnego modelu takie jak przygotowanie danych czy ich eksploracja.
